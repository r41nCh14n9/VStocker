## 1. 執行摘要

VStocker 是一套面向個人投資者的終端理財系統，以 **Bento Grid** 視覺化佈局為核心介面，同時追蹤**美股（US Equity）**與**台股（TWSE/OTC）**兩大市場。系統整合即時行情、技術分析、持倉管理、智慧警示與 AI 輔助洞察，讓投資人在單一畫面掌握雙市場脈動，做出更快、更有依據的決策。

### 核心價值主張

| 面向 | 描述 |
|---|---|
| 雙軌整合 | 美股＋台股同步追蹤，時區、匯率、假日自動處理 |
| Bento Grid UI | 模組化磁貼佈局，可拖曳、可客製化、資訊密度高 |
| 智慧理財 | AI 摘要、異常偵測、風險評分、自動警示 |
| 終端體驗 | 快捷鍵驅動、低延遲更新、離線快取 |

---

## 2. 專案目標與範疇

### 2.1 目標

1. 建立可運行的 Bento Grid 終端介面 MVP（Phase 1）
2. 整合美股（Alpha Vantage / Polygon.io）與台股（TWSE Open API）行情資料
3. 實現持倉管理、損益追蹤與資產配置視覺化
4. 加入 AI 智慧摘要與市場異常警示（Phase 2）
5. 支援個人化設定與跨裝置資料同步（Phase 3）

### 2.2 範疇（In Scope）

- Bento Grid 主控台介面（桌面優先）
- 美股即時/延遲報價 + 台股盤中/收盤資料
- 個股卡片、指數磁貼、投資組合概覽、損益圖表
- 股票篩選器、自選股清單管理
- 技術指標顯示（MA、RSI、MACD、布林通道）
- AI 市場摘要（整合 Claude API）
- 警示規則設定（價格突破、漲跌幅閾值）
- 本地資料持久化（SQLite / localStorage）

### 2.3 範疇外（Out of Scope）

- 實際下單 / 券商 API 串接
- 社群功能（討論、跟單）
- 行動端 APP（Phase 3+ 考慮）
- 加密貨幣市場
- 選擇權、期貨等衍生品追蹤

### 技術棧建議

| 層級 | 技術選項 | 備註 |
|---|---|---|
| 前端框架 | Next.js 15 + React 19 | App Router，SSR/CSR 混合 |
| UI 元件 | shadcn/ui + Tailwind CSS v4 | 快速構建磁貼元件 |
| Bento Grid | CSS Grid + react-grid-layout | 可拖曳佈局 |
| 圖表 | TradingView Lightweight Charts | 專業 K 線圖 |
| 狀態管理 | Zustand + TanStack Query | 全域狀態 + 資料快取 |
| 資料庫 | SQLite（本地）/ Turso（雲端） | 持倉、自選股持久化 |
| AI 整合 | Anthropic Claude API (Sonnet 4.6) | 市場摘要、洞察分析 |
| 即時資料 | WebSocket / SSE | 行情推送 |
| 語言 | TypeScript 5.x | 全棧型別安全 |

## 7. 風險管理

| 風險 | 機率 | 影響 | 緩解策略 |
|---|---|---|---|
| API 速率限制（Alpha Vantage 免費版每分鐘 5 次） | 高 | 中 | 實作本地快取層，考慮升級付費方案或改用 Polygon.io |
| 台股即時行情資料品質 | 中 | 高 | 備用方案：Fugle API 或 Yahoo Finance 爬蟲 |
| TradingView Charts 授權限制 | 低 | 高 | 備用方案：Recharts 或 Apache ECharts |
| Claude API 費用超支 | 中 | 中 | 實作 API 呼叫節流、回應快取，設定月度預算限制 |
| react-grid-layout 效能瓶頸 | 低 | 中 | Phase 3 優化，考慮 CSS Subgrid 替代方案 |
