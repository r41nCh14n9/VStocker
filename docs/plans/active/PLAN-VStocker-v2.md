## 1. 執行摘要

VStocker 是一套面向個人投資者的雙市場理財管理系統，以**前後端分離**架構為基底，提供美股與台股雙軌管理能力。系統核心採用 **Bento Grid** 視覺化儀表板，搭配股票矩形樹圖（Treemap）呈現版塊持倉概覽，並於第三階段導入 AI 個股分析，協助投資人做出更有依據的決策。

### 核心價值主張

| 面向 | 描述 |
|---|---|
| 前後端分離 | REST API + 前端分離，架構清晰、可獨立擴展 |
| 雙軌管理 | 美股＋台股獨立管理，一鍵 Switch 全系統切換 |
| 版塊化視角 | 以版塊（Sector）為核心組織股票，Treemap 直觀呈現 |
| 持倉追蹤 | 每位使用者獨立持倉，損益即時計算 |
| AI 洞察（P3） | 個股深度分析，Claude AI 輔助決策 |

## 2. 專案目標與範疇

### 2.1 目標

1. 建立可靠的前後端分離架構與資料庫基礎（Phase 0-1）
2. 實現使用者認證、授權與角色管理（Phase 1）
3. 完整的美股個股資料管理與使用者持倉功能（Phase 1）
4. 台股管理、雙市場一鍵切換、版塊管理、Treemap 儀表板（Phase 2）
5. AI 個股深度分析（Phase 3）

### 2.2 範疇（In Scope）

**資料管理面（後台）**
- 美股個股資料 CRUD（代號、名稱、產業、基本資訊）
- 台股個股資料 CRUD
- 版塊（Sector）建立與成分股管理
- 使用者管理與角色設定

**使用者功能面（前台）**
- 帳號登入 / 登出，JWT 身份驗證
- 美股持倉新增、編輯、刪除（成本價、股數、備註）
- 台股持倉同上
- 美股 / 台股 全系統 Switch Tag 一鍵切換
- 登入首頁儀表板：當前版塊 Treemap ＋ 統整資訊

**行情資料面**
- 串接外部 API 取得即時/延遲報價（美股：Alpha Vantage / Polygon.io；台股：TWSE / Fugle）
- 個股查詢頁面（搜尋、詳細資訊、歷史走勢）

### 2.3 範疇外（Out of Scope）

- 實際下單 / 券商 API 串接
- 社群功能（討論、跟單、複製投資組合）
- 行動端 APP
- 加密貨幣
- 選擇權、期貨等衍生品

### 技術棧

| 層級 | 技術 | 說明 |
|---|---|---|
| 前端框架 | Next.js 15 + React 19 | App Router，Server / Client Components |
| UI 元件 | shadcn/ui + Tailwind CSS v4 | 快速構建一致介面 |
| 圖表 / Treemap | Recharts / D3.js | 矩形樹圖、K 線走勢 |
| 狀態管理 | Zustand + TanStack Query | 全域狀態（Switch Tag）+ API 資料快取 |
| 認證 | Auth.js (NextAuth v5) | JWT Session，支援 Credentials Provider |
| ORM | Prisma | 型別安全資料庫存取 |
| 資料庫 | PostgreSQL | 使用者、股票、持倉、版塊資料 |
| 後端 API | Next.js Route Handlers | RESTful API，前後端分離介面 |
| 外部行情 | Alpha Vantage + Polygon.io (US)、TWSE + Fugle (TW) | 報價資料來源 |
| AI 整合 | Anthropic Claude API (Sonnet 4.6) | Phase 3，個股分析 |
| 語言 | TypeScript 5.x | 全棧型別安全 |

## 4. 資料模型概觀

```
User
  ├── id, email, passwordHash, role (ADMIN / USER)
  ├── marketMode: 'US' | 'TW'          ← Switch Tag 個人設定
  └── currentSectorId                   ← 儀表板預設版塊

Stock (US & TW 共用表，以 market 欄位區分)
  ├── id, ticker, name, market ('US' | 'TW')
  ├── sector (外鍵 → Sector)
  └── exchange, currency, description

Sector
  ├── id, name, market ('US' | 'TW')
  └── stocks[]                          ← 成分股

Portfolio (使用者持倉)
  ├── id, userId, stockId
  ├── shares, costPrice, currency
  └── notes, createdAt, updatedAt
```

## 8. 風險管理

| 風險 | 機率 | 影響 | 緩解策略 |
|---|---|---|---|
| Alpha Vantage 免費版限速（5 req/min） | 高 | 中 | 必須實作報價快取層（P1-C-06），考慮 Polygon.io 備援 |
| TWSE API 不穩定或格式異動 | 中 | 高 | 封裝成 adapter 層，便於替換；備用 Fugle API |
| Treemap 效能（大量個股渲染） | 中 | 中 | 限定每版塊顯示上限（如 50 支），搭配 virtualization |
| PostgreSQL 部署成本（本地開發） | 低 | 低 | 開發環境用 Docker Compose；生產可用 Supabase 免費層 |
| Claude API 費用（Phase 3） | 中 | 中 | 節流設定、回應快取 24h，設定月度 budget alert |
| Auth.js v5 Breaking Changes | 低 | 中 | 固定版本、寫整合測試確保升級可靠 |
